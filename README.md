# 🌍 Local Language Phrasebook App

An offline mobile app for learning and preserving local languages through simple everyday phrases.

## 📖 Overview

This project is a beginner-friendly mobile app designed to help people learn and preserve local languages through simple, everyday phrases.

The current version focuses on **Mokpe**, with English phrases and their Mokpe translations organized into useful categories.

The app is built with Flutter and designed to work offline.

---

## 🎯 Project Goals

- Promote local language learning and preservation
- Build a simple and useful mobile app from scratch
- Learn GitHub collaboration as a team
- Gain practical experience in mobile app development with Flutter

---

## 🚀 Features (Version 1.0)

- 📱 Splash screen
- 🏠 Home screen
- 📂 Browse phrases by category
- 🔤 View English → Mokpe translations
- 🔎 Search phrases in English or Mokpe
- ⭐ Add and view favorite phrases
- ℹ️ About screen
- 🔄 Navigation between Home, Categories, Favorites, and About
- 📱 Responsive layout for mobile and web
- 📴 Phrase data stored locally for offline use

---

## 📚 Categories

The app currently includes 6 categories:

- Greetings
- Family
- Food
- Travel
